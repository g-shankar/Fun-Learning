# Art

Blender-built 3D assets, modeled with headless `bpy` Python scripts
(`blender --background --python script.py`).

- `pip/` — Pip the mascot: build script, preview renders, GLB exports, skins.
- `words/` — one folder per alphabet word-item (apple, bear, cat, …), each
  with its build script, renders, and GLB.

Rule: nothing lands in the game until its renders are judged good.
